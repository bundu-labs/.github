## The Bundu Foundation

The Bundu Foundation stewards the commons of the ecosystem. It owns the
IP — the standards, the doctrine, the research, the Seven Minerals and
the documentation system — and governs. It will be the sole issuer of
all four tokens. It is a Zimbabwe company limited by guarantee;
**incorporation is pending**.

The ecosystem stands on three pillars, each with its own canonical
document:

| Pillar               | Role                                                                   | Canonical document                                                                                              |
| -------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Bundu Foundation** | Owns the IP and governs the commons.                                   | [The Bundu Order](./canonical/BUNDU_ORDER.md)                                                                   |
| **Nyuchi Africa**    | Operates everything that runs, and builds the Nyuchi products.         | [The Nyuchi Architecture](https://github.com/nyuchi/.github/blob/main/profile/canonical/NYUCHI_ARCHITECTURE.md) |
| **Mukoko**           | The consumer surface, and the first tenant of Nyuchi's infrastructure. | [The Mukoko Manifesto](https://github.com/mukoko-dev/.github/blob/main/profile/canonical/MUKOKO_MANIFESTO.md)   |

[The Bundu Order v5.0.0](./canonical/BUNDU_ORDER.md) is the
mathematical architecture of the ecosystem and holds the Locked Count
Register. Where documents disagree on anything technical,
[the Nyuchi Architecture](https://github.com/nyuchi/.github/blob/main/profile/canonical/NYUCHI_ARCHITECTURE.md)
wins.

## The enterprise

`bundu-labs` is the enterprise. It holds the Bundu Foundation's
open-source defaults and these repositories:

- [`zimbabwe-information`](https://github.com/bundu-labs/zimbabwe-information) —
  the Zimbabwe Information Platform behind
  [travel-info.co.zw](https://travel-info.co.zw). CC BY 4.0.
- `bundu-docs` — Bundu documentation (internal visibility).

Bundu Foundation projects that have their own organisations:

| Organisation                                | Project                                                                                              |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [`mzizi-dev`](https://github.com/mzizi-dev) | **Mzizi**, the open frontend architecture and design system ([mzizi.dev](https://mzizi.dev)).        |
| [`siafuDB`](https://github.com/siafuDB)     | **SiafuDB** and **SiafuDB-Kuzu**, the embedded graph database for device, edge and Web3. Apache 2.0. |
| [`openNTL`](https://github.com/openNTL)     | **NTL**, the Neural Transfer Layer: signal-based transfer replacing request-response. Apache 2.0.    |

Harare Metro and Bundu Education are designed. Nyuchi Gov Tech is
governed by the Foundation and operated by Nyuchi.
